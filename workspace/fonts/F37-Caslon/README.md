# F37 Caslon font asset

The renderer expects `F37Caslon-BoldDisplayCondensed.otf` in this directory. The font files are not included in this repository because the available copy is marked free for personal use only and no redistribution license was supplied.

Obtain the font from its rights holder and confirm that your intended use is covered by the applicable license before placing it here. The renderer will report a clear missing-font error until the required file is installed.
